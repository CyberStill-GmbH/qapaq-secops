# Informes de avance

Reportes puntuales para alimentar el Daily Scrum y a los stakeholders (Product
Owner, Riesgos No Financieros). Complementan el registro operativo continuo en
[`daily-scrum.md`](../daily-scrum.md); no lo sustituyen. Cada informe cita su
evidencia (commit, run de CI, capturas reales) y no declara `DONE` un
componente que el [plan por componentes](../component-delivery-plan.md) no
respalde.
